# SQL Lab

This repository contains my SQL lab programs and practice work completed as part of my Computer Science & Engineering coursework.

The lab covers SQL fundamentals including database creation, table operations, data insertion, filtering, updating, deleting records, and SQL predicates.

## 🛠️ Technologies Used

- MySQL
- SQL

## 📚 Topics Covered

### 1. Database & Table Operations
- Creating databases
- Selecting databases using `USE`
- Creating tables
- Describing table structure
- Dropping tables

### 2. Data Manipulation
- `INSERT`
- `UPDATE`
- `DELETE`
- `SELECT`

### 3. Filtering & Conditions
- `WHERE`
- `AND`
- `OR`
- `BETWEEN`

### 4. SQL Predicates
- `LIKE`
- Pattern matching using `%`
- Pattern matching using `_`
- Email-based filtering
- Name-based filtering
- Range-based filtering
